# Come By Shop

🌐 **Live:** [come-by-shope-latest.vercel.app](https://come-by-shope-latest.vercel.app)

Food ordering platform built for a client: menu, combos, cart, user accounts and an admin panel.

**Stack:** Next.js (App Router, SSR) · Fastify · PostgreSQL · Drizzle ORM · JWT / OAuth · WayForPay · Cloudinary · Vitest

- Email verification, Google OAuth and 2FA
- Online payments via WayForPay, SMS and email notifications
- Fastify REST API with request validation, rate limiting and security headers
- Frontend and backend covered with Vitest tests
